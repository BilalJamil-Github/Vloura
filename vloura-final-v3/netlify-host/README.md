# Vloura – NETLIFY HOST (client demo)

Form yahan pehle jaisa hi hai: "Send on WhatsApp" aur "Send by Email" (mailto). Koi key/setup nahi chahiye.
`noindex` laga hua hai taake demo Google mein na aaye.

## Deploy
1. https://app.netlify.com/drop kholo
2. Poora `netlify-host` folder drag & drop karo (index.html + images/ + netlify.toml)
3. Ya GitHub repo connect karo: Build command khali, Publish directory `.`

## Content (updated)
- `images/` mein hero, gallery aur posters ab client ki videos ke sabse clear frames se bane hain.
- `videos/` mein 16 chuni hui clear videos hain (8 Client Stories, 8 Features & Events). Sab 464x832 H.264, audio hata di gayi hai.
- Videos sirf play dabane par load hoti hain, is liye page tez rehta hai.
- Logo mark `images/logo-mark.png` (navbar aur favicon).
- Mazeed behtar quality ke liye client se original (non-WhatsApp) videos/photos mangwa lo, aur same naam se replace kar do.
